# Pizza Shop Order Summary Specification

1. The application shall calculate the total price of an order.
2. Each order item shall have a name, quantity and unit price.
3. The total shall be calculated by multiplying quantity by unit price for each item.
4. The application shall display the names and quantities of ordered items.
5. The application shall display the final order total in RM.
6. The order summary shall update when the order items or quantities change.
